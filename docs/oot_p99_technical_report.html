Heurística de empate

Cuando el mejor y el peor promedio de cortes coinciden a la precisión reportada, el informe declara que no existe separación útil. El orden se trata como desempate determinista y no como evidencia para priorizar o descartar variables.

Controles y límites

  • Los percentiles se calculan sobre la población OOT completa deduplicada por entidad.
  • La regla es inclusiva (>=); los empates pueden elevar el volumen sobre el 1% nominal.
  • P99 es una regla relativa de priorización, no una probabilidad de fraude ni un FAR garantizado.
  • La eliminación de variables requiere validación entre semillas/ventanas y una ablación controlada.
